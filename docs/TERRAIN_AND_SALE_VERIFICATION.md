Compatibility: new palms, drill, PLAT and MK art are optional enhancements for older caches. Saved local MIX stages can repopulate them without a network download. Until then, unavailable new scenery is omitted, missing PLAT uses the existing original pavement, and a missing MK keeps the existing standing building through the timed sale before removal. That legacy sale path is a static compatibility behavior; exact reverse animation is verified with complete original artwork.

The 126-file artwork-only legacy cache is verified for the default battlefield. Catalog maps additionally require their existing core theater palettes, base tiles and neutral structures; a pre-native cache cannot supply those without saved complete archives. Previously selected native-map caches remain compatible when only the new optional enhancements are missing. A successful archive selection records optional files absent from that archive, so reopening it does not repeatedly extract the same unavailable artwork.
